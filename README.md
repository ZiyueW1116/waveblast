# Waveblast（波波气）v0.1

一个服务器权威的多人同步回合制合成对战游戏原型。TypeScript npm workspaces：纯函数规则引擎、共享协议与数据、Fastify/Socket.IO 服务端、React/Vite Web。

## 启动

需要 Node.js 22+（推荐 24 LTS）。

```bash
npm install
npm test
npm run dev
npm run dev:web
```

浏览器访问 `http://localhost:5173`。服务端默认 `http://localhost:3000`，SQLite 文件为 `game.db`。生产环境必须设置 HTTPS、`NODE_ENV=production` 和准确的 `WEB_ORIGIN`。

## 已实现

- 用户名密码注册/登录，Argon2id，256-bit 随机 HttpOnly Session Cookie，登录限流。
- 创建/加入/开始房间，最多 12 人；活跃局在单进程内存，5 秒权威回合。
- direct 与 synthesis 为同一种回合动作；按实例消费材料，产物本回合打出、下一回合可用。
- 单体目标、龙波/镰刀群攻、闪避方向、攻转防、护/盾、持续防御和护甲死亡规则。
- 规则引擎无网络/数据库/时钟依赖，可确定性重放。

## 第一版明确采用的歧义策略

- 已锁定动作即使玩家本回合死亡仍生效（同步结算）。
- 多个单体攻击先求和并消耗同一防御池；群攻取最高值，再使用剩余防御；群攻不打施放者。
- 招式存在任意配方路径包含冲拳/旋风/左右波，就分别覆盖下地/上天/左右；等价运数至少 4 覆盖全部方向。
- 配方不同路径能量不一致时取最大等价运数。此规则集中在 `packages/game-data/src/index.ts::energyOf`，便于调整。
- 铜墙铁壁的 1 点一次性盾在全部攻击与防御计算之后、扣除护甲和死亡判定之前结算。只要最终伤害大于 0 就抵挡 1 点并立即消失（不要求该伤害致死）；持续效果在打出回合计入并于回合末递减。
- 未提交动作视为空过。盾系仅当所有伤害被防御时获得全额护甲；击穿则不获得。

## 边界

Web 已覆盖注册、房间、直接出招，以及选择合成产物和具体未消费材料实例进行合成。SQLite 通过服务端持久层集中使用，换 PostgreSQL 时不影响规则引擎。房间状态暂不持久化，进程重启会丢失进行中的对局。
